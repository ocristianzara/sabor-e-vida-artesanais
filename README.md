# Sabor e Vida Artesanais — Pães Artesanais em Campos do Jordão

> Landing page de vendas moderna, elegante, imersiva e interativa desenvolvida para a **Sabor e Vida Artesanais**, padaria artesanal localizada no **Mercado Municipal de Campos do Jordão (Box 10)**.

---

## Destaques da Experiência

1. **Hero Section Cinematográfica (Dobra 01):**
   - Vídeo *full-bleed* de fundo exibindo manteiga derretendo em pão quentinho recém-saído do forno.
   - Tipografia refinada e acolhedora com paleta de cores artesanal (`#f5ede8` e `#bb7840`).
   - Botões de conversão direta para o WhatsApp.

2. **Scroll Storytelling (Canvas Frame-by-Frame):**
   - Animação cinematográfica sincronizada 100% com a rolagem do usuário através de 55 frames.
   - 5 etapas narrativas do processo artesanal:
     * *Etapa 01 — A Origem:* Melhores ingredientes selecionados.
     * *Etapa 02 — O Trabalho Manual:* A perfeição nos detalhes da massa.
     * *Etapa 03 — O Respeito ao Tempo:* Sem pressa, paciência e fermentação.
     * *Etapa 04 — A Transformação:* O calor do forno transformando a massa.
     * *Etapa 05 — O Ponto Perfeito:* Pão dourado e crocante saindo do forno.

3. **Vitrine dos Pães:**
   - Cards com as especialidades (Pão Caseiro Tradicional, Pão Recheado, Pão Artesanal Dourado, Pão Nobre Trançado, Pão da Serra, Pão Rústico).
   - Botões de pedidos específicos para cada pão no WhatsApp.

4. **História do Fundador:**
   - Fotografia autêntica do padeiro e narrativa sobre a dedicação diária no Mercado Municipal.

5. **Como Chegar com PIN Pulsante Interativo:**
   - Localização no Mercado Municipal de Campos do Jordão com mapa e indicador com efeito radar.
   - Link oficial para navegação e rotas no Google Maps.

6. **Conversão Final & Informações:**
   - Horários de atendimento (Segunda a Sábado, das 8h às 18h).
   - Link para o Instagram oficial: [@saborevidaartesanais](https://www.instagram.com/saborevidaartesanais).
   - WhatsApp direto: (12) 99631-9214.

## Tecnologias

- **HTML5 Canvas & JavaScript Puro:** Controle de renderização frame-a-frame de alta performance.
- **Tailwind CSS:** Design responsivo e utilitário moderno.
- **React & TypeScript:** Componentes modulares prontos para TanStack Router (`src/components/site/*`).
- **Google Fonts:** Cormorant Garamond & Plus Jakarta Sans.

---

## Como Executar

### Visualização Imediata
Basta abrir o arquivo `index.html` em qualquer navegador.

### Projeto React
```bash
npm install
npm run dev
```
